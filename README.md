# Digitalna menza

Timski projekat za predmet **Inovacije u IT-u** - veb aplikacija za Studentski centar Kragujevac:
dopuna studentske kartice, kupovina obroka (QR bon), plaćanje smeštaja, dnevni i nedeljni jelovnik
i mini kviz o aplikaciji.

## Pokretanje

**Sada (samo HTML/CSS/JS):** otvori folder u VS Code-u, instaliraj preporučene ekstenzije
(VS Code ih sam ponudi), pa desni klik na `index.html` -> **Open with Live Server**.

**Kad se doda PHP:** projekat mora biti u `C:\xampp\htdocs\menza`, uključi Apache i MySQL
u XAMPP Control Panel-u i otvori `http://localhost/menza/`.

## Struktura

```
index.html      prijava
css/style.css   stilovi
js/login.js     provera forme za prijavu
```

## Rad sa Git-om

1. Pre rada: **Pull** (preuzmi izmene kolege).
2. Radi na svojoj grani (`luka-...` ili `kolega-...`), ne direktno na `main`.
3. Posle rada: **Commit** sa jasnom porukom (npr. `Dodata stranica jelovnika`) i **Push**.
4. Na GitHub-u otvori **Pull request** ka `main`; drugi član pogleda i spoji.
